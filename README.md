# Warehouse Inventory Management System: Manual Testing Project

Manual testing practice project on a small warehouse inventory web application.

## About
- **Application under test:** a practice inventory web app (`app/index.html`) with login, add item, goods received, goods issued, search, edit and delete. The app was provided for practice and contains intentionally planted defects.
- **My role:** Tester. I analysed requirements, wrote test cases, executed them and logged defects.
- **Tools:** Excel (test cases), Jira (bug tracking), Chrome DevTools.

## Requirements covered
R1 Login, R2 Add item, R3 Unique Item ID, R4 Goods received, R5 Goods issued, R6 No issue above available stock, R7 Quantity 1 to 10000 whole numbers, R8 Search, R9 Edit and delete, R10 Low stock warning.

## Techniques used
Black box testing, Boundary Value Analysis, Equivalence Partitioning, Negative testing.
